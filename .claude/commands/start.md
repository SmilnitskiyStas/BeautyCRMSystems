description: Класифікувати завдання через task-intake і запустити потрібних агентів
argument-hint: <опис завдання>
---

Завдання: $ARGUMENTS

1. Запусти субагента `task-intake` із цим завданням (якщо аргументів немає — візьми завдання з `BEAUTY_CRM_PROMPT.md`, Крок 1).
2. За його результатом коротко покажи: тип, складність, ризики, список агентів і порядок.
3. Якщо потрібні уточнення — запитай через AskUserQuestion.
4. Запусти агентів за `candidate_agents` згідно з `workflow/task-dag.md` (незалежних паралельно), `project-manager` веде статуси.
5. Наприкінці запусти `review-orchestrator`.
Не імплементуй сам: код пишуть субагенти.
