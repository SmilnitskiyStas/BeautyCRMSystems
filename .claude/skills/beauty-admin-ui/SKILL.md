---

- Структура `frontend/features/beauty-*`: `types.ts`, `api/`, `hooks/`, `components/`. React Query для серверного стану, Zustand лише для UI.
- Екрани: Огляд, Календар (блок = тривалість послуги, легенда типів), Клієнти й профіль, Спеціалісти й профіль, Ціни та акції, Аналітика, AI-асистент, Канали.
- Меню зліва однакове на всіх екранах; плаваюча AI-іконка внизу праворуч, контекст залежить від екрана.
- Доступність: реальні `button`/`a`/`label`, цілі натискання ≥44px, контраст ≥4.5:1.
- Поведінку й структуру брати з одного потрібного прототипу `docs/beauty-crm/prototype/*.dc.html`, не копіювати код дослівно.
