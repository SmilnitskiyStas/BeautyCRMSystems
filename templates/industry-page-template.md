# Industry Page Template

**Джерело:** структура галузевої сторінки, адаптована з практики SEO-орієнтованих галузевих лендингів
**Використання:** один екземпляр на галузь (`/industries/{slug}`). **Правило унікальності контенту (обовʼязкове):** без doorway pages — кожна опублікована галузева сторінка повинна мати унікальний контент, реальні приклади проблем, конкретні рішення і власні metadata. Не публікувати сторінку, поки вона не відповідає цій вимозі.

---

### 1. Галузь
_Яка галузь (приклад галузей — адаптувати під власну ЦА: retail, restaurants, healthcare, beauty, construction, logistics, education, startups, local-business — або будь-яка інша релевантна галузь, з обґрунтуванням)._

### 2. Релевантні рішення
_Обрати релевантну підмножину рішень, що реально відповідають потребам цієї галузі, не весь перелік одразу. Приклад можливих рішень (адаптувати під фактичний портфель послуг): сайт меню, онлайн-бронювання, доставка, інтеграція з CRM, програма лояльності, особистий кабінет, аналітика, push-повідомлення, мобільний застосунок. Для кожного обраного пункту — одне речення, чому це релевантно саме цій галузі._

### 3. Реальна проблема (real-problem framing)
_Конкретний, впізнаваний приклад проблеми бізнесу в цій галузі — не абстрактний жаргон, а те, що власник бізнесу впізнає як «це про мене»._

### 4. Пропоноване рішення
_Як саме команда вирішує проблему з пункту 3 — конкретно, з посиланням на релевантні послуги (`/services/*`) чи кейси (`/projects/*`), якщо є відповідні._

### 5. Унікальні metadata
_Власні `title`/`description` для uk/en — не шаблон із заміненою назвою галузі. Ключові слова — природні запити цієї галузі, не механічна підстановка._

### 6. Релевантний CTA
_Заклик до дії, сформульований для цієї галузі — напр. «Обговорити проєкт для {галузі}» з посиланням на `/start-project`, за потреби з UTM-міткою (напр. `?utm_campaign=local_business`) для outbound-використання._

---

## Перевірка перед публікацією (обовʼязково)
- [ ] Контент унікальний, не є перефразованим шаблоном іншої галузевої сторінки
- [ ] Приклад проблеми реальний і конкретний, не абстрактний
- [ ] Запропоновано конкретні рішення, не загальний список послуг
- [ ] Сторінка корисна незалежно від того, прийшов відвідувач з пошуку чи з outbound-посилання
- [ ] Власні metadata (title/description) для uk/en
